# AssetHub 운영전환 설계안 v2.2 — 자산번호 체계 (2026-10-27)

v2.1(`docs/운영전환_설계안_v2.1.md`)에서 **자산번호 부분만** 바꾼 문서입니다. 나머지는 v2.1·v2 그대로입니다. 운영 DB에 반영 완료(user_version 2).

## 1. 결정 사항

| 항목 | v2.1까지 | v2.2 |
|------|----------|------|
| 형식 | `{법인}-{유형}-{4자리}` (예: `DR-NB-0001`) | `{법인}-{대분류}-{유형}-{4자리}` (예: `DR-IT-NB-0001`) |
| 대분류 | 없음 | IT(IT기기), FN(가구·비품), RE(연구장비) — 기준정보에서 추가 가능 |
| 셀럭스 법인 코드 | SL | **CX** (Cellux) |
| 자산번호 변경 | 불가 (번호 = 자산의 기준 키) | **가능** — 라벨에는 QR만 인쇄 |

## 2. 번호와 식별 분리

- 자산마다 바뀌지 않는 내부 번호(정수)를 따로 둡니다. QR 주소, 이력, 요청, 실사는 모두 내부 번호를 씁니다.
- 사람이 보는 자산번호는 별도 칸이며 중복될 수 없습니다.
- 그래서 자산번호가 바뀌어도 이미 붙인 QR 라벨은 그대로 같은 자산을 엽니다.

## 3. 번호가 바뀌는 경우

- 자산의 법인 또는 유형을 바꾸면 서버가 새 번호를 발급합니다.
- 이력에 `번호변경` 항목(`이전 번호 → 새 번호`)이 남습니다.
- 한 번 쓴 번호는 다시 쓰지 않습니다. 순번은 법인·유형 조합별로 이어집니다.
- 유형은 대분류 하나에 속합니다. 같은 유형 코드(예: ET)가 다른 대분류에 따로 있을 수 있습니다.

## 4. 기존 자산 변환

- 기존 4자리 순번을 유지하고 대분류 IT를 끼웠습니다. 예: `DR-NB-0001` → `DR-IT-NB-0001`, `SL-MN-0007` → `CX-IT-MN-0007`.
- 기존 유형은 모두 IT 소속입니다.
- 결과: 186대 (DR-IT 143, TC-IT 27, CX-IT 16). 이력 300건 모두 새 내부 번호로 연결 확인.

## 5. 엑셀 자산 양식

- "법인코드" 다음에 "대분류코드" 칸이 추가됐습니다.
- 자산번호를 직접 적을 때는 `{법인}-{대분류}-{유형}-0000` 형식이어야 합니다. 비우면 자동 발급입니다.
